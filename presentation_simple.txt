                    SLIDE 5: SYSTEM CALLS
═══════════════════════════════════════════════════════════════

Key System Calls Used

• fork()     - Parallel stock fetching
• pipe()     - Inter-process communication
• waitpid()  - Process synchronization
• socket()   - Network connections
• signal()   - Alert handling (SIGINT, SIGALRM)
• mmap()     - Persistent price history
• select()   - Non-blocking keyboard input


═══════════════════════════════════════════════════════════════
                    SLIDE 6: DEMO - WATCH MODE
═══════════════════════════════════════════════════════════════

Feature: Multi-Stock Watch Mode

Command: ./marketpulse watch AAPL MSFT GOOGL

• fork() creates child process per stock
• pipe() transfers data to parent
• Real-time updates every 5 seconds
• Sparkline charts for price history
• Keyboard controls (Q, S, P, +, -)


═══════════════════════════════════════════════════════════════
                    SLIDE 7: DEMO - ALERTS
═══════════════════════════════════════════════════════════════

Feature: Price Alert System

Command: ./marketpulse alert AAPL 190

• signal() handles SIGINT (Ctrl+C)
• alarm() triggers periodic checks
• Visual flash + audio bell on alert
• Graceful shutdown with signal handlers
