═══════════════════════════════════════════════════════════════
                    SLIDE 7: STEP-BY-STEP WORKING
═══════════════════════════════════════════════════════════════

Step-by-Step Working

1. User enters command (e.g., ./marketpulse watch AAPL)
2. CLI parser interprets the command
3. Network module establishes SSL connection to Finnhub API
4. Stock data fetched using socket() and SSL_read()
5. JSON response parsed to extract price data
6. For multiple stocks, fork() creates parallel processes
7. Data transferred via pipe() to parent process
8. Display engine renders table with sparkline charts
9. AI module analyzes data and provides insights
10. Alert engine monitors thresholds using signals

═══════════════════════════════════════════════════════════════
                    SLIDE 9: SYSTEM CALLS USED
═══════════════════════════════════════════════════════════════

System Calls Used

• fork()      - Create child processes for parallel fetching
• pipe()      - Inter-process communication for data transfer
• waitpid()   - Synchronize parent-child processes
• socket()    - Create network connections to APIs
• connect()   - Establish TCP connections
• select()    - I/O multiplexing for non-blocking input
• signal()    - Handle SIGINT for graceful shutdown
• sigaction() - Advanced signal handling for alerts
• alarm()     - Timer-based periodic price checking
• mmap()      - Memory-mapped files for persistent history
• msync()     - Sync memory to disk
• mkfifo()    - Named pipes for live JSON streaming
• tcgetattr() - Get terminal attributes for raw mode
• tcsetattr() - Set terminal for keyboard controls
• kill()      - Send signals to background processes
